# 兵符 · New Era Xiangqi

> **你和对手抢同一副牌，用象棋的走法在棋盘上厮杀，谁先吃掉对方主将谁赢。**

《兵符》是一个把**象棋的移动逻辑**和**卡牌的资源争夺**拼在一起的桌游项目：
象棋是信息全公开的博弈，加上牌以后变成「公开棋盘 + 隐藏手牌」——
你知道场上的马在哪，但不知道对手手里还捏着几张兵、几张炮。
每一次摸牌都是在抢资源，每一次部署都是在暴露意图。

本仓库包含：

- ✅ 完整的规则书与设计笔记（**思路文档**都在这里）
- ✅ 可打印的原型牌面 / 棋盘，以及网页试玩 Demo
- ✅ Godot 4 数字版实现（纯逻辑引擎 + 水墨界面 + 313 条测试断言）

## 设计思路概述（详见设计笔记）

1. **底层不发明规则**：棋子的走法、蹩马腿、炮架、九宫，全部照抄象棋。玩家已经会的，一个字都不改。
2. **卡牌只做两件事**：① 控制**谁能上场**（摸牌、手牌、人口）② 改动**地图**（桥、水、地形）。不去改棋子的走法。
3. **每条上限都必须有硬理由**：人口、士象数量、手牌——加它们不是为了"平衡微调"，而是因为不加**规则本身会崩**。

几个核心机制：

- **共用牌库**：一副牌两个人抢，被吃的牌进共用弃牌堆、牌库空了洗回来——牌不会真正消失，这是"缴获"味道的来源。
- **人口上限 8 + 解散**：8 人口可以是 8 个小兵，也可以是 4 台战车，这是本作最核心的取舍。
- **三条桥**：过河只能走列 3 / 5 / 7 的桥，「往哪儿部署」因此成了最重的一个决策。
- **取消将军**（现行）：谁真的吃掉主将谁赢；「将军规则」正在评估加回（见待确认文档）。

## 数字版（Godot）

[`兵符-godot/`](./兵符-godot/) 是 Godot 4.7.2 实现，**可以开局对着打了**：
有棋盘、有棋子、有手牌、能部署 / 装备 / 移动 / 吃子 / 断桥 / 结束回合，一路能打到分出胜负。

```bat
cd 兵符-godot
run.bat            :: 开游戏
run.bat all        :: 跑全部测试（引擎 + 界面 + 护栏 + 自对弈，共 313 条断言）
run.bat shot       :: 渲两张图验收界面
```

引擎层是纯逻辑（绝不 extends Node、种子可注入、状态变化只走 `do_*`），
所以撤销、回放、联网、AI 搜索都有现成的地基。架构细节、踩过的坑、路线图见
**[`兵符-godot/README.md`](./兵符-godot/README.md)**。
